## 1. Project

- Repo `dviree/noopzone`, a fork of NOOP (offline companion app for WHOOP 4.0 / 5.0 / MG straps).
- Working branch: `claude/zone2-coaching-tsn511` (PR #1 against `main`). Push only to this branch.
- The owner uses the **iPhone** app only, sideloaded through SideStore. Android/macOS exist but are not built by the owner.
- Read first: `AGENTS.md` (hard rules), `docs/CONTRIBUTING.md`, `docs/BUILD.md`, `docs/IOS.md`.
- `project.yml` is the XcodeGen source; never hand-edit or commit `Strand.xcodeproj`.

## 2. Owner's working rules

1. **Test before shipping.** Never dispatch an IPA build until "App build (macOS + iOS)" (both legs + `Test Strand`) and "Swift Packages CI" are green on that exact commit.
2. Bump `CURRENT_PROJECT_VERSION` in `project.yml` for every new iOS build (currently **437**; `MARKETING_VERSION` 11.9.0). A marketing bump also bumps `versionName` in `android/app/build.gradle.kts`.
3. Design tokens only (`StrandPalette`, `StrandFont`, `NoopMetrics`).
4. Every new UI string gets translations in `Strand/Resources/Localizable.xcstrings` (de, es, fr, it, pt-PT, pl, ru, zh-Hans, zh-Hant), checked by `Tools/i18n_audit.py --ci origin/main`.
5. BLE: no destructive commands, no hard-coded frame bytes in app code; BLE behaviour must be verified on a real strap.
6. No servers, accounts, telemetry or cloud.
